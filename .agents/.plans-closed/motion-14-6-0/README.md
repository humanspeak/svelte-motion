## Findings considered and rejected

- **`motion.svg` ignores style changes (#2365; c70eb9ace, 407f8a010)**: svelte-motion's SVG styles flow through the
  same reactive style chain as HTML (`_MotionContainer.svelte` around lines 305, 1428, 1505); there is no memoised
  props object to go stale.
- **Snapshot a `layoutId` lead before commit (#2514; cfb176b10)**: svelte-motion hands off a cached rect
  (`currentVisualPageRect()`, refreshed by `observeMove`) rather than measuring at teardown, and
  `e2e/layout-id/shift-swap.spec.ts` covers the reported case. A layout-animating-ancestor variant is untested;
  worth a test if a report comes in.
- **`data-grabbed` (a11b0cd47)**: only ever existed on upstream's unreleased branch.
- **Tree-shaking `/* @__PURE__ */` annotations (03f341c43)**: nothing analogous in svelte-motion.
- **A public `@humanspeak/svelte-motion/testing` entry for `stepFrames`**: upstream ships none; 010 keeps the helpers
  test-only.
