## Findings considered and rejected

- Replacing the AnimatePresence clone-based exit architecture: out of #449's
  scope; clones are detached elements that cannot fight the VE (see plan 004).
- Subclassing `VisualElement` for a Svelte-specific renderer:
  `HTMLVisualElement`/`SVGVisualElement` already implement all abstract
  members; a subclass adds surface without benefit.
- Adopting upstream `VisualElementDragControls` wholesale: props/context shape
  is React-specific; plan 005 ports the write-path contract instead. Revisit
  after 005 as a follow-up issue.
